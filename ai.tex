\frontchapter{LLM Use Declaration}

I used large language models to generate most of the data analysis code for the evaluation in Section~\ref{sec:forward:evaluation}, then carefully reviewed the code to ensure its correctness.
When writing this thesis (but not the underlying papers), I used LLMs for proofreading, light editing, literature search and bibliography management.
Except as declared above, I did not use LLMs to write substantial amounts of text or code, to propose research hypotheses or to generate scientific findings, either in this thesis or in the underlying papers.
